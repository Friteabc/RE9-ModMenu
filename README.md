# RE9 Menu

Created by **friteabc** for Resident Evil Requiem.

**This mod is not stable yet. Bugs and crashes can occur. Back up your saves.**

Install [REFramework](https://github.com/praydog/REFramework), then copy `package/reframework` into your game folder.
Launch the game and press **Insert** to open or close the menu. Change shortcuts in **Hotkeys**.
